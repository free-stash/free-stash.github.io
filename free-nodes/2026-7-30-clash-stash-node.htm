一、Quantumult简介

Quantumult是一款在iOS平台上广泛使用的网络代理工具，它不仅支持VPN连接，还支持HTTP/HTTPS代理、Shadowsocks、Vmess等多种协议。通过Quantumult，用户可以快速访问被封锁的网站、提高访问速度、保证上网隐私，甚至实现流量的分流管理，避免常见的网络限制。

Quantumult的主要功能：

  1. 网络代理：支持多种代理协议，如Shadowsocks、Vmess等，可以根据需求设置不同的代理规则。

  2. 分流管理：允许用户对不同的应用程序或网站设置不同的网络策略，以达到加速和节省带宽的效果。

二、如何在iOS设备上下载Quantumult

1. 检查设备兼容性

在进行下载之前，首先要确保您的iOS设备已更新至最新的操作系统版本。Quantumult建议至少在iOS 13或更高版本上使用，因此，如果您的设备系统较旧，建议先进行系统升级。更新后的设备才能保证应用的正常运行，避免出现不兼容的问题。

2. 访问App Store下载Quantumult

Quantumult目前只在App Store中提供下载，因此，您需要通过官方渠道来获得应用。以下是下载Quantumult的步骤：

  1. 打开App Store：在您的iOS设备上找到并打开App Store。

  2. 搜索Quantumult：点击屏幕底部的“搜索”按钮，在搜索框中输入“Quantumult”，并点击搜索。

下载完成后，Quantumult应用将自动安装在您的主屏幕上，您可以点击图标启动应用。

三、如何安装与配置Quantumult

在成功下载并安装Quantumult后，您需要进行一些必要的设置，才能充分利用其强大的功能。

1. 打开应用并授权权限

首次打开Quantumult时，应用会请求一些权限，确保它可以正常工作。这些权限可能包括网络访问权限、后台运行权限等。您需要按照提示授予相关权限，确保应用的顺利运行。

2. 配置网络代理

Quantumult支持多种网络代理协议，您需要根据自己的需求来设置。最常见的配置方式是使用Shadowsocks或VPN协议。如果您已经拥有代理服务器的配置信息（如IP地址、端口、加密方式等），可以通过以下步骤进行配置：

  1. 打开Quantumult应用：点击主屏幕上的Quantumult图标，启动应用。

  2. 进入配置界面：在应用主界面，找到并点击“配置”选项。

  3. 输入代理配置：在配置页面中，您需要输入代理服务器提供的配置信息。通常情况下，代理提供者会提供一个链接或QR码，您只需导入该信息即可。

  4. 保存并应用设置：输入完配置后，点击保存按钮，确保设置生效。

配置完成后，为确保连接正常工作，您可以进行连接测试。Quantumult提供了“测试连接”的功能，帮助您检查代理配置是否正确。

  1. 在应用中选择“测试连接”。

  2. 稍等片刻，Quantumult将测试您的网络连接，并显示连接结果。如果测试结果显示连接正常，您就可以开始使用Quantumult了。

FAQ

V2Ray 的 ws+tls 传输模式有什么优点？
ws+tls 模式利用 WebSocket 伪装成普通 HTTPS 流量，使得防火墙难以区分代理与正常访问。该模式兼容性强，适合部署在支持 Nginx 或 Caddy 的 Web 服务器上。
Netch 的 TUN 模式与 SOCKS 模式有何差异？
TUN 模式通过虚拟网卡拦截所有流量，更接近系统级代理；SOCKS 模式则仅作用于指定应用。TUN 模式更适合全局代理需求，而 SOCKS 模式轻量快捷，适用于游戏或单软件加速。
Shadowrocket 的节点测速结果如何优化网络体验？
Shadowrocket 测量节点延迟和丢包率，将延迟低的节点优先使用。结合策略组和分流规则，可提升网页浏览、视频播放和游戏的访问速度和稳定性，优化整体网络体验。
如何配置 Clash 以支持局域网内设备共享代理？
启用 Clash 的 HTTP/SOCKS5 本地监听并在局域网设备上设置该代理地址为网关；若使用 TUN 模式需配合路由器或透明代理实现全局共享，注意开启访问控制避免未经授权的外部访问。
SSR 是否支持 UDP 协议转发？
原版 SSR 并不完全支持 UDP 转发，但部分魔改版本（如 SSRR）支持该功能。可在配置中开启 udp-over-tcp 模式或使用 Socks5 UDP relay 方案实现游戏等实时通信的代理需求。
VMess AEAD 加密在安全性方面有何优势？
AEAD 加密可防止数据篡改、重放攻击和流量特征泄露。在高封锁环境下保证节点可用，提升数据安全和连接稳定性，同时降低被检测风险，确保长期安全访问。
Clash 支持哪些协议？
Clash 支持多种主流代理协议，包括 VMess、VLess、Trojan、Shadowsocks、Snell、Socks5 等。通过配置文件或订阅源，用户可以灵活组合不同协议的节点，实现复杂的分流策略与优先级控制。
Mellow 如何通过配置实现多出口分流？
Mellow 可在配置文件中定义多个 outbound，并结合 routing 规则实现按域名、IP 或策略组分流。这样不同类型的流量可走不同节点，提高使用体验。
Shadowrocket 的分流规则如何支持视频加速？
通过分流规则，将流媒体域名匹配到高速节点，其他网站走普通节点。这样可以保证视频播放流畅，同时节约带宽资源，提高整体网络效率和体验。
Sing-box 的 DNS 模块如何工作？
Sing-box 内置 DNS 模块，支持 fake-ip 模式和纯直连模式。它可根据规则选择不同的上游 DNS 服务，从而实现国内外域名智能分流，减少访问延迟。
